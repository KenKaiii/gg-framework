GG Coder est un agent de code pour ordinateur qui tire davantage de l'abonnement IA que vous payez déjà.

> ⭐ **Si GG Coder vous fait gagner du temps ou de l'argent, donnez-lui une étoile.** C'est le principal moyen pour d'autres développeurs de le découvrir.

## Pourquoi GG Coder

- **Plus de travail par forfait.** Le plus rapide et le plus économe des 20 agents que j'ai mis en compétition sur le même modèle. Claude Code a consommé 169 % de plus pour le même travail.
- **Du vrai code, pas des suppositions.** Agent Steroids cherche du vrai code open source, à jour, sur votre machine. Pas de serveur MCP limité en débit, pas de limites.
- **Terminé veut dire vérifié.** Ken Autopilot poursuit le travail jusqu'à ce qu'il soit réellement vérifié.
- **Livrez proprement, même en débutant.** Coder n'est qu'une partie du travail. Des vérifications en un clic pour la sécurité, la conformité, la protection des données, l'accessibilité, les tests et plus, avec un score Project health, pour que vous n'ayez pas besoin de savoir quoi demander.
- **Vos abonnements.** Forfaits Claude, ChatGPT, Kimi Code, MiniMax et MiMo, toute clé API ou modèles locaux.

## Également inclus

- **GG Goals :** confiez un objectif entier, une équipe de workers le mène à bien.
- **Chat :** des conversations qui se souviennent du contexte.
- **GG Motion :** transforme vos idées en vidéos.

## Démarrer

1. Installez GG Coder :

   **macOS (Apple Silicon) :** [téléchargez la dernière version](https://github.com/KenKaiii/gg-framework/releases/latest) et ouvrez le `.dmg`.

   **Windows :** [téléchargez la dernière version](https://github.com/KenKaiii/gg-framework/releases/latest) et lancez l'installeur `.exe`.

   **Linux (x86_64) :** [téléchargez la dernière version](https://github.com/KenKaiii/gg-framework/releases/latest) et installez le `.deb` (`sudo apt install ./GG*.deb`) ou le `.rpm` (`sudo dnf install ./GG*.rpm`).

   **Développement :** avec Node.js, pnpm et les [prérequis Tauri](https://v2.tauri.app/start/prerequisites/) installés :

   ```bash
   git clone https://github.com/KenKaiii/gg-framework.git
   cd gg-framework
   pnpm install
   pnpm build
   pnpm --filter gg-app tauri dev
   ```

2. Ouvrez l'app, connectez votre fournisseur d'IA et choisissez Code, Chat ou Motion.

## Construire avec le framework

Vous voulez le moteur sans l'app de bureau ? Utilisez les mêmes paquets dans vos propres apps. N'installez que ce dont vous avez besoin.

- [**@kenkaiiii/gg-ai**](packages/gg-ai/README.md): Se connecter aux fournisseurs d'IA et recevoir les réponses en streaming.
- [**@kenkaiiii/gg-agent**](packages/gg-agent/README.md): Créer des agents qui utilisent vos outils et accomplissent des tâches.
- [**@kenkaiiii/gg-core**](packages/gg-core/README.md): Choix du modèle, authentification et détection des modèles locaux.
- [**@kenkaiiii/ggcoder**](packages/ggcoder/README.md): L'agent de code, les sessions et les outils derrière l'app et la CLI.

Pour votre propre agent, commencez ici :

```bash
npm install @kenkaiiii/gg-ai @kenkaiiii/gg-agent
```

# Fonts shipped with the GG Coder app

| Font | Author | Used for | Terms | File |
|---|---|---|---|---|
| Sora | The Sora Project Authors | App interface text | SIL OFL 1.1 | `sora/OFL.txt` |
| Young Serif | The Young Serif Project Authors | Display headings | SIL OFL 1.1 | `young-serif/OFL.txt` |
| m5x7 | Daniel Linssen | Pixel text: Goal world, critter bubbles, Home tags | CC0 1.0 (public domain) | `m5x7/LICENSE.txt` |
| Alagard | Hewett Tsoi | Pixel titles and plate buttons | Free, credit to the author | `alagard/CREDIT.txt` |

The "GG Coder" title image (`../home/gg-coder-title.png`) is drawn from
Alagard by `gg-app/scripts/gen-home-title.py`. The Goal world's pixel text is
baked from m5x7 by `gg-app/scripts/gen-pixel-font.py`
(`src/pixel-font-m5x7.ts`).

Pixel font credits: m5x7 by Daniel Linssen, Alagard by Hewett Tsoi.

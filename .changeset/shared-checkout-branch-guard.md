Each window can now be on its own branch. The Git panel (the branch key by the message box) has a Branches tab: filter, create or pick a branch. When no other window uses the folder, picking switches it in place; when other windows do, this window alone re-opens in its own git worktree for that branch (under `~/.gg/worktrees`, with ignored `.env` files or `.worktreeinclude` entries copied) and keeps its conversation, while the other windows stay where they are. When other windows share the folder you choose: its own worktree for this window (the default), or switch the folder for everyone. A new worktree runs the project's setup once as a visible background task (`setup` in `.gg/worktree.json`, otherwise the install command for its lockfile), and Home lists a project's worktrees with their branch and status, opens them, and removes GG-made ones (asking first when they have uncommitted changes; the branch stays). Each conversation remembers its branch, so reopening it, from Home or after a restart, comes back on that branch. Nothing assumes a branch named `main`. Agents can no longer switch the branch of a checkout another window, or their parent agent, also uses (`git switch`, `git checkout <branch>`, `gh pr checkout`); they are pointed to a worktree instead. Every window follows its branch live, including switches made in a terminal, and its agent is told when it changed.
